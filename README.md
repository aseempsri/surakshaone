# SurakshaOne

Marketing site for SurakshaOne.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

Every push to `main` runs GitHub Actions and deploys to GitHub Pages:

https://aseempsri.github.io/surakshaone/

In the repo: **Settings → Pages → Source → GitHub Actions**.
